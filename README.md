# 🎬 SRK Animated Film Portfolio

An interactive and cinematic portfolio website inspired by the iconic journey and style of Shah Rukh Khan (SRK).

## ✨ About the Project

This project is a visually immersive film portfolio created using modern web technologies. It combines cinematic animations, movie-inspired visuals, and a smooth user experience to showcase selected films and creative work.

The website features an animated opening/loading experience followed by an interactive portfolio interface.

## 🚀 Features

- 🎞️ Cinematic loading animation
- ✨ Smooth animations and transitions
- 🎬 SRK-inspired film portfolio
- 🖼️ Movie photo showcase
- 📱 Responsive design for desktop and mobile
- 🎨 Modern cinematic UI
- ⚡ Lightweight and interactive frontend
